## 等 Codex 可用之前，最有價值的補充資料
- [ ] 原版 Story 主選單、選區域、選起始、分岔地圖、戰前、戰中、獎勵、背包、進化、道館、聯盟與通關畫面，各提供 1–2 張截圖（不要包含帳號或金鑰）。
- [ ] 記錄同一區域的一次完整前段遊玩：節點選擇 → 戰鬥 → 升級／獎勵，附截圖與顯示數值，作為**行為參考**，不是抽取原始碼。
- [ ] 指定第一個驗收地區（建議先關都作驗證，再擴充其他地區）。
- [ ] 確定難度預設組合（見 DIFFICULTY_DESIGN.md），尤其要不要允許中途切換。
- [ ] 確認遊戲介面要只做繁體中文，或同時保留英文。
- [ ] 取得原作者及相關素材的使用許可，或決定使用原創角色與美術素材。
- [ ] 如欲將遊戲部署到公開網址，先完成權利確認；目前不啟用 GitHub Pages。

## 來源與風險紀錄
- 官方參考：https://pokelike.xyz/ ，公開網站有舊版快取，不可僅以網頁爬取結果推定最新版本。
- 候選第三方專案：https://github.com/pcasaspere/pokelike_v2 。根目錄目前含 README、AGENTS、index、css、js、sprites 等，未見 LICENSE（2026-10-29 檢查），**不能因為公開就複製進新專案**。
- Pokelike Wiki 歷史資料：https://pokelike.wiki/sources/ ，僅供查找版本化行為，需按原始來源核對。
- 技術獨立性：不可匯入未獲授權原始碼、受保護素材、官方帳號資料或使用者個人存檔。
