# 劇情模式需求規格（草案）

> 狀態：需求定義，不是官方 v3.5 規則驗證結果。引用 Pokelike 只作功能對照，未授權原始碼與受保護素材不得直接匯入。

## 產品目標
製作可在桌面與 iPhone Safari 使用、具繁體中文介面與可選難度的獨立 Roguelike 闖關網頁遊戲。保留使用者偏好的「節點選路 → 收集隊伍／獎勵 → 自動戰鬥 → 強化 → 道館／聯盟」循環。在具合法權利與可驗證資訊之前，不宣稱與官方版本內容或畫面相同。

## 劇情模式完整流程
1. 主選單：新遊戲／繼續／設定／備份；可選地區與難度。
2. 開局：選模式（一般／如有需求再新增高難度）、可用起始角色、確認隊伍。
3. 路線：顯示目前位置及下一步**實際可到達的節點**；移動必須遵循有向路徑。
4. 事件：訓練家戰、野生遭遇、可選收編、道具、被動獎勵、交易、補給、隨機事件、首領。
5. 戰前：檢視敵我資訊、隊伍順序、裝備與恢復狀態。
6. 自動戰鬥：在同一規則引擎內處理出手順序、招式選擇、傷害、暴擊、屬性、異常狀態、特性與裝備觸發；保留可檢視的逐回合日誌。
7. 戰後：勝敗判定、經驗／明確升級事件、隊伍變更、進化分支、消耗品、紀錄。
8. 地區進度：道館 → 地區特殊事件 → 聯盟 → 冠軍 → 通關及重開。
9. 遊戲中斷：任何合法暫停點可安全存檔與恢復，不跳回舊節點也不重複獎勵。

## 系統與資料介面（先決定契約，後面再填授權資料）
- 地區資料：區域 ID、顯示名稱、可用開局選項、地圖組態、道館與聯盟、解鎖規則、內容版本。
- 角色資料：內部 ID、屬性、基礎能力、進化、招式、特性與可裝備欄位。不要複製未授權素材或資料集。
- 戰鬥資料：攻防、HP、速度、異常狀態、有效能力階級、招式、傷害類型、觸發事件清單、亂數種子。
- 道具資料：唯一 ID、作用範圍、觸發時機、疊加規則、上限、取得與使用限制。
- 地圖資料：節點 ID、節點類型、明確的邊、事件條件、亂數種子、可重現的事件序列。
- 存檔資料：schemaVersion、gameVersion、runId、regionId、difficultySnapshot、seed、team、inventory、mapProgress、eventFlags；不得夾帶任何官方帳密或存檔憑證。

## 介面驗收
- 桌面 Chrome / Edge 可操作；iPhone Safari 直向可讀、按鈕可觸控、不必靠 hover。
- 地圖可辨識現有節點、可選節點與已走路線；不存在的邊不可選。
- 道具、能力、招式效果均有繁體中文說明及清楚單位／倍率。
- 自動戰鬥必須有摘要與詳細日誌，讓玩家理解失敗原因。
- 每次新的遊戲選難度；可在主選單重新設定預設值。

## 必須逐地區核對的內容
- 起始選項、地圖數與每張節點事件
- 八大道館（如該地區適用）、首領隊伍、聯盟順序及特殊規則
- 可遇見角色／稀有度／進化、道具供應與商店／交換
- 經驗獎勵、失敗條件、進度保存與通關解鎖

## 本期不包含
- 對戰塔、每日挑戰、排行榜、多人連線、與官方帳號同步。
- 未經授權的程式、美術、聲音或遊戲資料重發布。
- 宣稱完全複製官方版本的圖像或專屬表現。
